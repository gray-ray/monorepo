非常好的问题 ✅
这个是 **pnpm monorepo + TypeScript + 外部依赖** 常见的坑点之一。

你描述的情况是：

> 在 monorepo 根目录安装了 `moment`，但在某个 `packages/**` 子包里 `import moment from 'moment'` 报错：
> ❌ 找不到模块 “moment”

---

## 🧩 一、问题原因（核心）

TypeScript 的模块解析策略默认是基于包自身的 `node_modules` 目录。

但在 Monorepo 里：

- `moment` 安装在 **根目录 node_modules**
- 子包下 **没有自己的 node_modules**
- TypeScript 在默认模式（`node` 或 `classic`）下 **不会向上查找依赖**
- 所以报：`找不到模块 'moment'`

---

## ✅ 二、解决方案（推荐优先级）

### ✅ 方案 1：在每个子包 tsconfig.json 中设置

```json
{
  "compilerOptions": {
    "moduleResolution": "NodeNext"
  }
}
```

🔹 **推荐原因：**

- `NodeNext` 模式支持 Node 的真实查找规则（会向上递归查找 node_modules）
- 支持 ES 模块与 CommonJS 混合使用
- 未来 TypeScript 官方也推荐用这个模式

> ✅ 这是最简洁、官方认可的方案。

---

### ✅ 方案 2：添加 `paths` 别名（次优）

如果你不想改 `moduleResolution`，可以在根 tsconfig 设置路径映射：

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "moment": ["./node_modules/moment"]
    }
  }
}
```

🔹 这种方式让 TypeScript 知道 “moment” 实际上在根目录
🔹 但：

- 只影响类型检查（编译时）
- **运行时** 仍依赖 Node 的模块查找机制
- 不如 `NodeNext` 稳定

---

### ✅ 方案 3：在子包内部 `pnpm add moment -w`

`-w` 表示安装在 workspace 根目录（如果没加就会报错）。

如果你想明确声明依赖关系，可以让子包自己引用：

```bash
pnpm add moment -w
```

然后在子包 `package.json` 明确声明：

```json
{
  "dependencies": {
    "moment": "workspace:*"
  }
}
```

🔹 优点：

- 子包依赖清晰（不会出现“偷偷依赖”）
- TypeScript 和运行时都能找到
- 符合 monorepo 依赖声明规范

🔹 缺点：

- 比 `moduleResolution` 配置繁琐一点

---

## 🚀 三、推荐最终做法

如果你是使用 pnpm + TypeScript monorepo：

### ✅ 根 tsconfig.json

```json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "NodeNext",
    "target": "ES2020",
    "resolveJsonModule": true,
    "skipLibCheck": true
  },
  "include": ["packages/**/*"]
}
```

### ✅ 子包 package.json

```json
{
  "name": "@your-scope/tree-utils",
  "dependencies": {
    "moment": "workspace:*"
  }
}
```

### ✅ 根 package.json

```json
{
  "dependencies": {
    "moment": "^2.30.1"
  }
}
```

> ✅ TypeScript 能正确解析
> ✅ 运行时能正常加载
> ✅ 符合 monorepo 最佳实践

---

## 💡 快速检查是否生效

1. `tsc --traceResolution`
   可以看到 TypeScript 实际解析 moment 的路径
2. 确认输出中有：

   ```
   Found 'moment' in node_modules at ../../node_modules/moment
   ```
